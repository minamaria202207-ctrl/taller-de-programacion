# Taller de Programación – Diagramas de flujo y Java

Solución del taller basado en el libro **Diagramas de flujo. Ejercicios y problemas** (P. Pérez-Lemaur). Se resolvieron **6 ejercicios por capítulo** (capítulos 2 a 5; el capítulo 1 es solo teoría).

Cada ejercicio tiene su propia carpeta con tres entregables:

| Archivo | Contenido |
|---|---|
| `requerimientos.md` | Análisis de requerimientos: enunciado, entradas, proceso, salidas, RF, RNF, restricciones y prueba real |
| `diagrama.drawio` | Diagrama de flujo para abrir en [Draw.io](https://app.diagrams.net) |
| `*.java` | Programa en Java comentado |

## Cómo ejecutar un ejercicio

```bash
cd capitulo2/ejercicio01_factorial
javac Factorial.java
java Factorial
```

Los ejercicios del capítulo 4 usan ficheros de texto: ejecútelos **desde la carpeta del ejercicio** (ya incluye datos de ejemplo).
