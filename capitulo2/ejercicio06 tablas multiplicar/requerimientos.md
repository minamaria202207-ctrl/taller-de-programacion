# Ejercicio 2.6 – Las 10 primeras tablas de multiplicar

## 1. Enunciado
Programar e imprimir las 10 primeras tablas de multiplicar (del 1 al 10, cada una multiplicada por 1 hasta 10).

## 2. Análisis

**Entradas**
- Ninguna.

**Proceso**
1. Para I desde 1 hasta 10 (tabla en curso):
2.    Para J desde 1 hasta 10: mostrar I x J = I·J.

**Salidas**
- 100 líneas con las 10 tablas de multiplicar.

## 3. Requerimientos funcionales
- **RF-01** Debe generar las tablas sin pedir datos.
- **RF-02** Debe usar dos ciclos anidados.
- **RF-03** Debe mostrar cada multiplicación con el formato `I x J = resultado`.

## 4. Requerimientos no funcionales
- **RNF-01** Lenguaje Java (JDK 8 o superior), ejecución por consola y sin librerías externas.
- **RNF-02** Código comentado, con nombres de variables significativos y una sola clase pública.
- **RNF-03** Mensajes claros al usuario (qué dato se pide y qué resultado se muestra).
- **RNF-04** El diagrama de flujo (`diagrama.drawio`) debe corresponder con el algoritmo programado.

## 5. Restricciones y supuestos
- El ciclo externo controla la tabla y el interno el multiplicador.
